# TF-QKD / FSO Quantum Communication Framework

A research-oriented implementation framework for studying **Twin-Field Quantum Key Distribution (TF-QKD)** and its potential deployment over **Free-Space Optical (FSO)** communication channels.

This project is being developed by **Anand Kumar**, B.Tech Electronics and Communication Engineering, under the guidance of **Prof. Neelkanth Kundu (Indian Institute of Technology Delhi)**, with academic supervision and support from **Prof. Yugnanda Malhotra**.

The framework combines theoretical foundations, security analysis, channel modelling, literature review, and simulation-based investigations into a unified research environment for quantum communication studies.

---

## Project Objectives

The framework aims to:

- Study the principles and security foundations of TF-QKD
- Implement and validate key protocol components through simulation
- Investigate secret-key generation under realistic channel conditions
- Explore deterministic FSO channel models as an extension toward free-space quantum communication
- Build a reproducible research platform for future protocol development and experimentation
